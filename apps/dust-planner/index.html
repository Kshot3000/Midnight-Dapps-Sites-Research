DUST Planner Pro
a modelled estimate, never a promise.

Estimate how much DUST a given amount of registered NIGHT can generate, and whether a planned fee spend fits that model. This is a static planner. It does not connect to a wallet, read an indexer, request keys, or submit transactions.

Official sources and parameters

The planner uses documented ledger 9 DUST parameters. It does not copy Ledger 8-era numbers, and it does not treat the older tokenomics whitepaper speck ratio as authoritative. These are ledger parameters, not constants: each network stores its own set, and governance can replace it. This page does not read live parameters from an indexer.

Cited docs

  • Managing DUST for transaction fees — formulas for cap, generation per second, and time to cap; linear generation and decay; fee payment in DUST; a printed Mainnet parameter read at block 2,809,291.
  • DUST architecture — initial parameters, units (STAR and SPECK), and the 604,815-second time to cap.
  • Ledger 9 upgrade notes — “The DUST parameters stay the same: 5 DUST per NIGHT at the cap, and about 7 days to reach the cap.”

What this model assumes

One registered, unspent NIGHT UTXO of the amount you enter, generating from empty at the start of the period. Official docs note that spending registered NIGHT, including a transfer to yourself or a change output, starts decay on the old DUST UTXO and creates a new one from zero. Unregistered NIGHT generates nothing. This tool does not model multiple UTXOs, fee-market prices, or a live testnet or mainnet balance.
