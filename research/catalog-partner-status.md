# GROK-7 — Official-catalog partner verification

**Checked:** 2026-11-24 (America/Chicago)
**Checked by:** Grok swarm (GROK-7, Bob Research)
**Scope:** Partner cards in the official Midnight [ecosystem catalog](https://midnight.network/ecosystem-catalog). This fills the games, NFT, and mainnet DeFi gaps in `research/ecosystem-directory.md` (GROK-PROP-B2). Results are suggested corrections only — this PR does not edit the directory (GROK-8 is Victor's).

## Method and limits

I opened the catalog on 2026-11-24. Direct HTTP to `midnight.network` and `midnight.fun` often returned Vercel HTTP 429 (same as GROK-1 and GROK-6). WebFetch returned the catalog page. I also read the Sanity CMS that backs the official site (`project` documents in project `330xhmya`, dataset `production`, `visible: true`): **105** visible cards. The rendered-page extract had **104** `###` headings; CertiK appears in the page body without its own heading in that extract. I treat the CMS visible set as the catalog.

The catalog is large, so this pass verifies **every visible card** in the priority categories the board named — Gaming, NFT, DeFi, Prediction Market, Tokenized RWAs, Identity Solutions, and Wallet — plus the named examples PLAY NATION (tagged DAO, not Gaming) and DEGA (visible card is tagged AI; a second, hidden Gaming+AI record exists in the CMS). That is **36** cards. The other **69** visible cards are counted and listed below; I did not open those 69 partner sites in this pass, except where they were already opened in GROK-1 or GROK-6 (for example VIA Labs, Sig Network, Fireblocks, Midnight Explorer).

I did **not** connect a wallet, sign a transaction, install an extension or mobile app, request faucet tokens, create an API key, or sign up for an account. **Nothing is listed as a live Midnight product unless I opened it and have evidence that does not need a wallet signature.** A marketing homepage, a logo row, or a 2025 partnership blog is not a live product. Preview and Preprod are **testnets**. Stagenet is a permissioned test network. Mainnet is production.

**Stack pins (current, ledger 9):** Compact toolchain **0.36.1**, Midnight.js **5.0.1**, Wallet SDK **2.0.1**, DApp Connector API **4.1.0**, proof server **9.0.2**, indexer **4.4.101** (see `research/stack-versions.md`). No Ledger 8 material was copied into this file.

## Bottom line

- The official catalog is a partner directory, not a list of live Midnight dApps. Many cards are companies, integrations, or announcements.
- In the priority set I could independently evidence only **two live Midnight wallet products** I opened without installing them: **Lace** and **1AM**. Official wallet docs opened today (the page is dated "Accurate as of June 2026") also list those two as available DApp Connector targets.
- **Moneta's USDM-on-Midnight issuer page** opened, and GROK-6 already has public mainnet transfer evidence for that unshielded VIA route. I did not mint or transfer. The issuer page still says "Testnet today (Cardano preprod to Midnight preview), mainnet next per VIA," which GROK-6 found out of date.
- I did **not** open a playable Midnight game, or a Midnight NFT marketplace I could use. Paima's public site is still its Xai / Arbitrum games. Dust 2 Dust exists as a GitHub repo that documents a local deploy, not a hosted game I could play. `midnight.fun` / `midnight.fun/dapps`, which the April 2026 official blog described as a live game gallery, now renders as a Midnight marketing homepage. PLAY NATION's public site was effectively empty. DEGA's site is an AI agent / "mint your masterpiece" builder with no Midnight product I could open.
- **NMKR** markets Midnight NFT minting on its homepage. [MidnightPunks](https://midnightpunks.com/) calls itself the first Midnight collection and says minting is **temporarily paused** while NMKR fixes the minting terminal. I did not mint.
- **DeFi:** GalaxySwap's own site says it is live on **Midnight Preprod** (testnet). NorthStar's beta swap UI opened; I still could not confirm the network and did not swap. CSWAP's Midnight pages still advertise an LBE "coming Jan 15th" and use "can enable" language. Ascend's marketing banner says "Public Mainnet is live"; its docs describe a public testnet, a **closed private mainnet beta** for prediction perps, and a DEX guide that claims Midnight Mainnet. I opened `dex.ascend.market` without a wallet — the shell loaded and the pair read **"Unavailable"**. I did not connect or trade, so I do not list Ascend as a verified live mainnet product.
- **Bodega** remains a Cardano prediction market plus a July 2025 official partnership. I did not open a Midnight Bodega product.
- Several 2025 wallet-integration announcements are still "coming soon," Cardano-side NIGHT claim/redemption, or undocumented on the vendor homepage I opened today. Official June 2026 docs list SubWallet and NuFi as available; those vendors' homepages did not mention Midnight. **urble's homepage today is a CHF / Bitcoin savings app** and does not mention Midnight; a December 2025 vendor blog says urble "is building on Midnight." That is a directory correction.
